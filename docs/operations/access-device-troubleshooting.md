# Access Device Troubleshooting

## Common Symptoms

- Access denied for an active member.
- Manual open fails.
- Temporary pass is not consumed.

## Checks

1. Confirm device status is active.
2. Confirm device organization and branch.
3. Confirm membership status and grace period.
4. Confirm temporary pass status, expiration and remaining uses.
5. Check audit logs and access logs.

## Hardware Integrations

Current access commands are simulated. Real turnstile or reader integrations belong to a later integration milestone.
