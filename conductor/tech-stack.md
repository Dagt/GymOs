# Technology Stack

## Backend
- **Language:** Java 25
- **Framework:** Spring Boot (v4.1.0) with Spring Modulith for modular architecture.

## Frontend
- **Language:** TypeScript
- **Framework:** Next.js (v16) and React 19.
- **Styling:** Tailwind CSS (v4) for utility-first styling.

## Infrastructure & Data
- **Primary Database:** PostgreSQL
- **Caching & Key-Value Store:** Redis
- **Object Storage:** MinIO
- **Environment:** Docker Compose for local development and orchestration.
